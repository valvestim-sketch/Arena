# RedPen — ассистент учителя английского

Проверка письменных работ за секунды: разметка ошибок прямо в тексте, оценка по критериям
(IELTS / ЕГЭ / письмо другу), упражнения на конкретные ошибки ученика и история прогресса.

Приложение выросло из задачи «как упростить жизнь учителю английского». Больнее всего —
вечерняя проверка письменных работ по 15–20 минут за штуку, поэтому автоматизирован именно этот этап.
Никаких внешних сервисов и ключей: всё считается локально в браузере, работы учеников никуда не уходят.

## Что умеет

**Проверка текста**

- **101 правило** в 5 категориях: грамматика (63), стиль (16), пунктуация (12), лексика (9), орфография.
- Отдельный слой — **типичные ошибки русскоязычных учеников**: калька с русского (_How do you think?_, _I am agree_, _I feel myself good_), предлоги (_depend from_, _married with_, _listen music_), коллокации (_make homework_, _do mistakes_, _make a photo_), приметы ЕГЭ-письма (_How are you? I am fine_, `etc.` в конце перечисления).
- **Орфография**: словарь английского языка (Hunspell, ~550 КБ, загружается один раз) + 170 «частых ошибок» с точной заменой (_becouse → because_, _goed → went_, _advices → advice_), плюс британские варианты написания и неологизмы (programme, podcast, influencer).
- **Ловит русские слова кириллицей** в английском тексте.
- Каждое правило не только помечает ошибку, но и **предлагает точную замену** и объясняет правило по-русски с примером.

**Оценка работы**

- 4 критерия: выполнение задания, организация и связность, лексика, грамматика и пунктуация — по шкале 1–9.
- Проверка требований формата: объём (hard/soft лимиты IELTS ≤250+, ЕГЭ 37 = 100–140, ЕГЭ 38 = 180–275), обращение и подпись в письме, наличие введения/заключения/мнения/примеров.
- Ориентировочная оценка (band) и уровень CEFR, который считается из критериев и статистики текста: длина и вариативность предложений, доля продвинутых конструкций (пассив, перфект, условные, придаточные), разнообразие лексики, повторяющиеся слова, типичная базовая лексика (_very_, _good_, _things_).

**Помощь в работе**

- **Разбор для ученика** — готовый текст «что исправить в первую очередь», примеры «было → правильно», что потренировать. Можно отредактировать, скопировать в мессенджер или скачать.
- **Тренажёр** — автоматические упражнения из ошибок этой же работы: выбор правильного написания и «исправьте предложение». Интерактивный режим для урока + кнопка «скопировать все упражнения».
- **Исправление в один клик**: «Исправить» меняет текст и запускает проверку заново; «Применить всё» выдаёт чистовик.
- **Личный словарь**: имена, города, названия компаний, которые проверяющий не должен считать ошибкой.
- **«Больше не показывать»** — если правило сработало зря, оно убирается из подсчёта.
- **Отчёт и печать**: «Скачать отчёт» (txt: критерии, замечания, исправленный вариант, упражнения, разбор) и печать/PDF через Ctrl+P (форматирование отчёта предусмотрено).

**Совместный режим (ученик — по ссылке)**

- Учитель в разборе работы открывает вкладку «Тренажёр» → **«Отправить ученику»** и получает ссылку.
- Ученик открывает ссылку на телефоне: отвечает на упражнения из **своих же ошибок**, после каждого ответа сразу видит правильный вариант и объяснение правила. Опечатки распознаются отдельно от ошибок («почти верно — только опечатка»).
- В конце ученик нажимает «Отправить результат учителю».
- Учитель в разделе **«Задания ученикам»** видит: кто выполнил, сколько верно, какие ответы даны по каждому упражнению, все попытки. Список обновляется сам, есть пометка «стоит вернуться к этим правилам на уроке».

**Работа с учениками**

- Карточка ученика: уровень, цель (ЕГЭ / IELTS / разговорный), заметки.
- История проверок: дата, формат, объём, оценка — с возможностью открыть любую проверку заново.
- **Что повторить на следующем уроке**: ошибки агрегируются по всем работам ученика и сортируются по частоте; одной кнопкой собирается план урока с разминкой из реальных ошибок.
- Все данные — только в этом браузере (localStorage). Есть бэкап всех данных в JSON.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173  (интерфейс + API совместного режима)
```

`npm run dev` поднимает сразу два процесса: интерфейс (Vite, порт 5173) и локальный API для заданий
ученикам (Node, порт 8787). Браузер обращается к API по тому же адресу — Vite проксирует `/api`.
Отдельные команды, если нужны: `npm run dev:web` (только интерфейс) и `npm run server` (только API).

Приложение открывается сразу; словарь орфографии подгружается в фоне при первом запуске.

```bash
npm run build        # tsc -b && vite build
npm run preview      # собранная версия
npm run smoke        # рендер всех экранов без браузера (SSR-проверка)
npm run test:answers # проверка сравнения ответов ученика (21 сценарий)
npm run engine:demo  # прогон движка по 4 демо-работам в консоли
npm run lint         # oxlint
```

В правом верхнем углу панели «Текст ученика» есть выпадающий список **«Пример работы…»** —
4 образца (слабый и сильный IELTS Task 2, письмо другу, ЕГЭ 38), на которых видно всю логику.

## Как это устроено

```
src/engine/          движок проверки (работает и в браузере, и в консоли)
  rules.ts           101 правило: шаблон → замена → объяснение, из списков глаголов
                     автоматически строятся правила словоизменения (he go → he goes)
  spell.ts           словарь Hunspell + «частые ошибки» + британские варианты
  text.ts            токенизация, предложения (с учётом e.g. и инициалов), статистика текста
  analyze.ts         сборка находок, оценка по критериям, упражнения, сообщение ученику
  taskTypes.ts       форматы работ и их требования
src/components/      интерфейс: проверка, разбор, тренажёр, ученики
src/lib/             storage (localStorage), клиент API, сравнение ответов, отчёты
server/index.mjs     локальный API совместного режима (Node без зависимостей)
scripts/dev.mjs      запуск интерфейса и API одной командой
scripts/             engine-demo (прогон в консоли), ssr-smoke (проверка рендера)
public/dict/         словарь en.aff / en.dic для проверки орфографии
```

Движок детерминированный и объяснимый: ни одного обращения к внешнему API, каждое замечание можно
проверить руками. Это принципиально для учителя — инструменту нужно доверять, а не «верить».
Правила расширяются одним объектом в `rules.ts`:

```ts
{
  id: 'l1-make-homework',
  category: 'lexis', severity: 'error',
  title: 'do homework',
  explanation: 'Домашняя работа «делается» через do, а не make.',
  example: 'I do my homework after dinner. ✅',
  pattern: /\b(make|makes|made|making)\s+(my|his|her|our|their|your|the|a)?\s*homework\b/gi,
  replace: (m) => `do ${m[2] ? m[2] + ' ' : ''}homework`,
}
```

## Где хранятся данные

- Проверки, ученики и личный словарь — только в браузере учителя (localStorage), на сервер не уходят.
- Задания ученикам и их ответы — в локальном файле `server/data/store.json` (в git не попадает).
  Это сделано, чтобы ученик мог открыть ссылку с телефона и результат вернулся учителю.
  Для работы внутри класса/кабинета достаточно локальной сети; для доступа из интернета приложение
  нужно развернуть на хостинге (`npm run build` + `npm run server`).

## Точность и ограничения — честно

- Это **ассистент, а не замена учителя**: смысловые ошибки, логику аргументации и уместность стиля проверяет человек. Баллы — ориентировочные.
- Оценка речи (speaking) и аудирования не проверяется — только письмо.
- Ложные срабатывания возможны: имена собственные, редкие слова, намеренные авторские обороты. Для этого есть личный словарь и кнопка «больше не показывать правило».
- Словарь орфографии — общий английский без узких терминов; незнакомые профессиональные слова лучше добавить в личный словарь.
- Оценка калибровалась вручную по 4 образцам и типовым работам B1–C1; на «пограничных» текстах она может отличаться от оценки экзаменатора на ±1 балл.
- Ссылка на тренажёр действует, пока запущен сервер заданий: это удобно для занятий и класса, но не публичный сервис.

## Куда развивать дальше

1. **Проверка произношения** — запись голоса ученика и разбор фонетических ошибок (уже можно считать приблизительно, но нужен настоящий ASR).
2. **Задания с картинки** — учитель фотографирует работу в тетради, распознавание текста → сразу проверка.
3. **Синхронизация с календарём уроков**: к уроку автоматически собирается «карточка памяти» по ученику.
4. **Коллекция материалов**: генерация worksheet-ов по ошибкам ученика с уровнями и ключами.
5. **Задания для группы**: одна ссылка на класс, таблица результатов по ученикам, авто-отчёт родителям.
6. **Больше экзаменационных форматов**: ОГЭ 35, CAE/CPE, деловые e-mail задания.
7. **Сервер в интернете**: развёртывание API и вход ученика по имени, чтобы ссылки работали вне кабинета.
8. **Повторные тренажёры**: автоматически собирать новое задание из ошибок, которые ученик не исправил с первого раза.
